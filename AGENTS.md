# DSH Workspace Skin

- Verify the installed DSH version and native interfaces before changing integrations.
- Prefer official theme tokens and stable UI extension slots. Keep decorative layers pointer-transparent and hidden from accessibility APIs.
- Keep balances tied to the selected provider; never replace unavailable data with zero or another account's balance.
- Prefer browser E2E with offline fixtures. Run the complete suite after implementation; retain reproducible reports and screenshots. Never use paid calls for tests.
- Keep private installation records, local configuration, credentials, and personal research out of version control.
