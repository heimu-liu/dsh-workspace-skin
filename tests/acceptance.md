# 第一版验收与失败场景（实现前记录）

在隔离的 DSH 0.2.2-rc.1 Web 运行时验证实际插件；不调用付费模型，不修改真实桌面 profile。

- 原生模块发现、依赖注入和插槽挂载失败；样式不能覆盖到真实 UI；禁用后样式、背景、插槽和监听器残留。
- 背景遮挡选择/输入/工具结果；移动端溢出；暗色主题不可读；动效暂停未持久化或忽视减少动态效果。
- 余额来源错误：切换模型仍显示旧来源；未登录、离线、权限拒绝、慢请求迟到时显示旧钱数；混合币种被相加；赠金被当成充值。
- 会话费用串线；分页只统计可见消息；换模型重算旧调用；重试漏计或重复 settlement 双计；缺 usage、缺路由、未知模型、价格区间以外的记录被当成零。
- 费用被误称完整账单：必须标明模型估算；子任务、压缩和搜索/抓取未纳入；节假日无法判断时按峰谷区间展示。
- 刷新后的偏好恢复与主对话完整投影重建；恢复默认后卸载清理。

验证使用浏览器 E2E 和实际 Host 的投影注册/回放，保留 JSON 报告与截图；不新增实现镜像式单元测试。

## 0.1.1 分层竹影：实现前失败场景

- 只移动整张图片，枝条和叶片没有相对运动；各层节奏完全同步或切换时突然跳动。
- 暂停只停止竹竿，叶片继续移动；减少动态效果时仍播放；恢复播放丢失原来的相位。
- 开关背景、刷新或切换会话后叠加多份背景；停用后仍残留装饰节点或观察器。
- 竹影捕获鼠标、盖住文字或造成窄屏横向溢出；动感靠提高不透明度实现而干扰阅读。
- 验收需保存相隔一段时间的两张画面和各层变换采样，证明层内相对运动；暂停、减少动态效果、输入、明暗主题与移动布局均通过后再更新桌面。
